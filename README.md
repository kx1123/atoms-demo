# Atoms 对话式应用工作台

通过对话生成、预览和修改单页网页应用，支持项目持久化、版本恢复以及独立 Docker 部署。本地开发无需云服务器或域名。

在线体验：[Atoms Demo](https://atoms.39.108.96.233.sslip.io)。无需注册即可测试。

## 启动

需要 Node.js 24 或更高版本。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:3100>。请固定使用这个地址，localhost 和 127.0.0.1 的浏览器会话互相独立。

生产构建可以使用 `npm run build`，随后使用 `npm start`。启动前先停止占用 3100 端口的旧进程。

## 模型配置

复制 `.env.example` 为 `.env.local`，填写服务商提供的配置并重启服务：

```dotenv
MODEL_BASE_URL=https://你的服务商/v1
MODEL_API_KEY=你的密钥
MODEL_NAME=模型名称
MODEL_DAILY_LIMIT=30
```

接口需兼容 Chat Completions：接收 `model`、`messages`、`stream:false`、`max_tokens`，返回 `choices[0].message.content`。服务端会自动补上 `/chat/completions`，也允许填写完整端点。支持 HTTPS 服务及本机 HTTP 模型。

密钥仅由服务端读取，不写入项目代码或预览页面。界面的“已配置”仅代表三个配置项齐全，首次生成才会验证实际连通性。没有凭证时可以打开明确标注的交互示例；示例不是模型生成，不会伪装成 AI 成功。

## 当前功能

- 项目列表、真实模型调用、SSE 阶段进度、连续对话修改。
- 完整单文件 HTML 生成，结构及脚本语法检查，失败后最多自动修复一次。
- 隔离 iframe 运行、桌面与手机宽度预览、代码查看和 HTML 下载。
- SQLite 保存项目、对话、运行和不可变版本；恢复历史会追加新版本。
- 受限存储桥接：生成代码可使用 `window.atoms.get(key, fallback)` 与 `window.atoms.set(key, value)` 保存 JSON 数据，单项目上限 100 KB。
- 预览异常上报，用户可主动发起一次修复；生成失败保留原版本。
- 匿名会话归属校验、同项目单任务、请求去重、过期版本保护、会话每日调用上限。

## 数据位置与隔离

默认数据库位于 `data/atoms.sqlite`，可通过 `ATOMS_DB_PATH` 指定。数据库、模型配置和构建产物都已加入 `.gitignore`。

浏览器 HttpOnly Cookie 标识匿名会话，清理 Cookie 后旧项目仍在数据库中，但新会话无法访问。请使用普通浏览器窗口保留项目。服务重启后未完成任务会标记为中断，可重新发送需求。

生成网页在 `sandbox="allow-scripts allow-forms"` 中运行，保留表单事件能力；CSP 禁止表单提交与外部网络资源，不授予同源、顶层跳转或弹窗权限。宿主只接受当前 iframe 与预览令牌匹配的消息。

本地启动脚本只监听回环地址。公开部署使用独立 Docker 应用、网关和数据卷，配置入口、环境变量和恢复方式见 [Docker 部署](deploy/README.md)。生成次数按匿名会话、网络和全站分别限制，并限制全站并发；实际额度上限以运行 env 为准。

## 验证

```sh
npm test
npm run typecheck
npm run build
node scripts/smoke.mjs
```

自动化测试使用独立的内存或临时数据库，不修改本地项目。模型流程测试使用明确的模拟服务响应，覆盖有限修复，不代表真实模型效果已验收。API smoke 测试需要本地服务正在运行，使用独立匿名会话。

浏览器体验：打开交互示例 → 新增任务 → 完成任务 → 筛选 → 刷新确认保留 → 查看代码和版本历史。线上验收已完成真实首次生成、一次连续修改、版本恢复及容器重建后数据保留；更多复杂需求仍需逐场景验证。

## 范围与限制

首版生成无需外部依赖的前端单页应用，不包含任意 npm 工程、后端服务或应用自身的账号体系。工作台持久化是真实数据库保存；生成网页的数据需通过存储桥接保存。版本恢复只恢复代码，应用数据不随代码一起回滚；历史预览中的操作不写入数据库。

代码下载包含当前已知的应用数据快照，可离线打开并交互，但独立文件刷新后的修改不会持久化。生成内容的静态检查和“预览已加载”状态，不代表功能语义已由浏览器测试通过。

交付说明见 [笔试提交说明](docs/笔试提交说明.md)，部署方法见 [Docker 部署](deploy/README.md)。
